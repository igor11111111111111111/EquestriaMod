# Справочник: как устроен The Old Realms

Разбор большого мода The Old Realms (TOR) для Bannerlord v1.3.15, сделанный 2026-09-15 перед его удалением с диска.
Цель — ориентир по архитектуре для мода Equestria. Код, модели и тексты TOR не копировались: здесь только описание
устройства, имена файлов/типов и короткие фрагменты форматов XML.

| Файл | О чём |
|---|---|
| [01_races_characters.md](01_races_characters.md) | Расы (skins.xml, скелеты, монстры, 85 action sets), персонажи и культуры, регистрация XML, локализация |
| [02_items_assets_mounts.md](02_items_assets_mounts.md) | Деление на модули, упаковка ассетов (tpac), броня и «шлемы-головы», оружие, **ездовые (единорог, демигриф)**, звуки, VFX |
| [03_code_systems.md](03_code_systems.md) | C#-архитектура, магия и ИИ колдовства, статус-эффекты, Ink-истории, свои поселения и религии, **своя глобальная карта**, GUI, сохранения, перевод |
| [04_magic.md](04_magic.md) | **магия подробно**: разбор системы заклинаний TOR по декомпиляции + наша реализация (мана, колесо на Q, заклинания) |

Самое важное для нас:
1. Раса = `<race>` в skins.xml (через `project.mbproj`) + 5 Monster + 85 action sets + `race=` у персонажей. Расы только дописывать в конец.
2. Антро-пони на `human_skeleton` — как вампиры/эльфы в TOR: новые меши, ванильные анимации. Свой скелет — как дварфы/орки, но нужны анимации, cloth bodies и Harmony-фиксы.
3. «Костюм пони» для теста = броня с `covers_head/body/legs/hands` — так TOR делает treeman/dryad.
4. Единорог TOR = `Type="Horse"` + `Monster.horse` + свой меш на `horse_skeleton`. Полёта в TOR нет — только своим C#.
5. Магия: данные в XML (`AbilityTemplate`, `TriggeredEffectTemplate`, `StatusEffectTemplate`) + движок в C#; расширение через `ScriptNameToTrigger`.
6. Своя карта: сцена `Main_map` в модуле Environment + Harmony-патч путей settlements/кэша.
7. Выпускать только `AssetPackages\*.tpac` + XML; изменения ванили — через одноимённые `.xslt`; строки — `{=id}`.
