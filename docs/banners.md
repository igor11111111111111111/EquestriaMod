# Знамёна: устройство, размеры, свои значки

Заметки по гербам держав и кланов. Собрано 25.09.2026 при подготовке своих значков.

## 1. Из чего собрано знамя

Знамя в игре — это не картинка, а **ключ** из двух слоёв по десять чисел, разделённых точками:

```
значок . цвет . цвет2 . ширина . высота . X . Y . обводка . зеркало . поворот
```

Первый слой — подложка (фон), второй — эмблема поверх неё. Так его собирает
`banner_key()` в `tools/make_world.py`:

```
11.<цвет>.<цвет>.4345.4345.764.764.1.0.0 . <значок>.<цвет2>.<цвет2>.512.512.764.764.1.0.0
```

Важное: **цвет задаётся номером из палитры игры, а не шестнадцатеричным кодом.** Палитра —
`BannerColors` в `Modules/Native/ModuleData/banner_icons.xml`, 229 цветов; наш код подбирает
ближайший к цвету державы (`nearest_color`).

## 2. Откуда берутся значки

`banner_icons.xml` описывает группы, которые видны в редакторе знамён. В ванили их шесть:

| id | Группа | Чего в ней |
| --- | --- | --- |
| 1 | Background | 36 подложек, каждая — **меш** (`mesh_name="banner_background_test_N"`) |
| 2 | Animal | 65 значков |
| 3 | Flora | 24 |
| 4 | Handmade | 48 |
| 5 | Sign | 64 |
| 6 | Shape | 36 |

Значки (237 штук, id от 100 до 535) — не меши, а клетки листа:

```xml
<Icon id="100" material_name="custom_banner_icons_01" texture_index="10" />
```

## 3. Размеры листа (главное)

Замерено по ванильным листам:

- лист — **2048 × 2048** пикселей;
- на листе **4 × 4 значка**, то есть клетка **512 × 512**;
- `texture_index` — номер клетки, **0…15**, слева направо и сверху вниз;
- **шестнадцать значков на материал**: в ванили 15 материалов (`custom_banner_icons`,
  `custom_banner_icons_02` … `_16`), у каждого свой лист;
- ванильные листы сжаты в **BC7** (`DXGI_FORMAT_BC7_UNORM`), поэтому `tpac_export texture … .png`
  их не разбирает — только `.dds`. Нам это не мешает: в редактор отдаём обычный PNG, сжатие он
  делает сам;
- материал использует шейдер **`gui_color_and_stroke`** с флагом **`alpha_test`**; цвет берётся из
  ключа знамени, поэтому сам значок — это форма, а не раскраска.

## 4. Что уже сделано у нас

| Файл | Зачем |
| --- | --- |
| `tools/make_banner_icons.py` | собирает лист `assets/banner_icons/eq_banner_icons_d.png` из гербов `assets/banner_icons/src/*.png` (по имени файла — по порядку клеток); с ключом `--test` кладёт заглушку, с `--numbers` — заглушку с номерами клеток |
| `Module/ModuleData/equestria_banner_icons.xml` | группа 7 «Эквестрия», значки с id 900…915 |
| `Module/SubModule.xml` | строка `<XmlName id="BannerIcons" path="equestria_banner_icons"/>` |
| `tools/banner_material.ps1` | материал `eq_banner_icons` копией ванильного |

Сейчас в листе **заглушка**: в каждой из шестнадцати клеток белый квадрат с чёрной каёмкой. Это
проверка размеров и того, что группа вообще появляется в игре.

### Порядок работы

1. `py -3 tools\make_banner_icons.py` — собрать лист;
2. импорт `assets\banner_icons\eq_banner_icons_d.png` в редакторе (Resource Browser → Import,
   пакет `banner_icons`);
3. `.\tools\banner_material.ps1` — материал `eq_banner_icons`;
4. запустить игру: в редакторе знамён появится группа «Эквестрия» с шестнадцатью значками.

### Как раздать значки державам

Номер значка державы берётся из `emblem` в `tools/world_data.py` (у клана — там же), а знамя
собирается в `make_world.py`. То есть достаточно поставить в `emblem` наш id (900…915) и пересобрать
мир — `py -3 tools/make_world.py Module`.

## 5. Картинки в правой панели редактора — это НЕ те же значки

Само знамя рисуется материалом (`material_name` + `texture_index`, нарезка 4×4 зашита в коде:
`TextureIndex % 4 * 0.25` по горизонтали и `/ 4 * 0.25` по вертикали). А плитки в списке выбора —
обычные **спрайты интерфейса**:

```xml
<Widget ... Sprite="@IconPath" />        <!-- GUI/Prefabs/BannerEditor/BannerEditor.xml -->
```

где `IconPath` — это просто номер значка (`BannerIconVM`: `IconPath = iconID.ToString()`).
Ванильные спрайты лежат в `Modules/Native/GUI/NativeSpriteData.xml`: категория **`ui_bannericons`**,
по спрайту на каждый id, размер **100×100**, всё упаковано в лист `ui_bannericons_1` (4096×1024).

Отсюда: **у своих значков панель остаётся пустой** — спрайтов с именами 900…915 в игре нет
(проверено 25.09.2026: на знамени номер виден, в списке клетка пустая). На сами знамёна это не
влияет, гербы держав раздаются в XML, а не выбором в редакторе.

Чтобы плитки появились, нужно добавить в модуль свой `GUI/<имя>SpriteData.xml` со спрайтами
900…915 размером 100×100 и лист-текстуру к ним. Важно: экран редактора грузит именно категорию
`ui_bannericons` (`UIResourceManager.LoadSpriteCategory("ui_bannericons")`), поэтому либо спрайты
кладутся в неё же вторым листом, либо свою категорию придётся грузить из кода. Делать это имеет
смысл после того, как появятся настоящие гербы: лист миниатюр собирается из той же картинки.

## 6. Грабли

- **У узла `BannerIcons` в `SubModule.xml` не должно быть `IncludedGameTypes`.** Знамёна читаются
  один раз при запуске модуля (`BannerManager.ResetAndLoad`), когда игры ещё нет: тип игры в этот
  момент пустая строка, а узел со списком типов в такой проверке отсеивается
  (`MBObjectManager.GetMergedXmlForManaged`). С перечнем типов группа в игру не попадала вовсе —
  редактор знамён показывал только ванильные (напоролись 25.09.2026). У ванильного узла
  `banner_icons` списка типов тоже нет.
- **Id значков не должны пересекаться с ванильными** (100…535) и между собой. Взят диапазон
  с 900 — с запасом.
- **Группа добавляется, а не заменяет.** Игра сливает `banner_icons.xml` всех модулей, поэтому
  ванильные группы остаются на месте; id группы (7) обязан быть свободным.
- **Имя материала в XML обязано совпадать** с именем, созданным `banner_material.ps1`
  (`eq_banner_icons`). Ошибка в имени не валит игру — значок просто не рисуется.
- **Подложки — это меши, а не картинки.** Своя подложка потребует моделирования, а не рисования;
  значок (`Icon`) добавляется листом, подложка (`Background`) — нет.
- **Значок — силуэт, а не картинка.** Проверено в игре 25.09.2026: белый квадрат с чёрной каёмкой
  вышел на знамени ровным пятном без каёмки. Цвет берётся из ключа знамени и заливает всё
  непрозрачное, собственный цвет пикселей не значит ничего. Рисовать заливку или обводку внутри
  герба бесполезно — **детали делаются дырками**, то есть прозрачностью: сквозь них видно цвет
  подложки. Так и устроена проверочная нумерация в `--numbers`.
- **Прозрачность значима.** Шейдер с `alpha_test`: то, что прозрачно в PNG, знамя не рисует.
  Поэтому гербы должны быть силуэтом на прозрачном фоне, а не картинкой с белым фоном.
