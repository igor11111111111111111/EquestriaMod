# Видео на фоне главного меню

Не гифка, а настоящее видео: **IVF с кодеком VP8 + отдельный OGG**. Разобрано 26.09.2026 по
`MBInitialScreenBase.RefreshScene` (декомпиляция) и по файлам ванили.

## Как игра выбирает ролик

- Просматривает `Videos\initial_menu\<любая папка>\` у **каждого активного модуля**.
- Из папки берёт пару: один `*_pc.ivf` и один `*.ogg`. Нет одного из двух — папка пропускается.
- Из всех найденных пар берёт случайную (зерно — текущая секунда) и играет по кругу.
- **Частота кадров зашита в игре — 24.** Ролик с другой частотой пойдёт быстрее или медленнее.
- Пропорции 16:9 игра подгоняет сама (`RefreshVideoAspect`), на ультрашироких мониторах обрезает.

Ванильные ролики (восемь папок в `Modules\Native\Videos\initial_menu`): VP8, 2560×1440, 24 fps,
по 130–330 МБ каждый.

## Как у нас

- Файлы: `Module\Videos\initial_menu\equestria\1440p_pc.ivf` + `equestria_menu.ogg`.
- Убрать ванильные из списка нельзя (Native всегда активен), поэтому `src/EquestriaMenuVideo.cs`
  подменяет путь в `VideoPlayerView.PlayVideo`: что бы игра ни выбрала из `initial_menu`, играет
  наш файл. Пока наших файлов нет, ничего не подменяется и меню остаётся ванильным.
- Заставка с логотипами (`TWLogo_and_Partners`) идёт мимо `initial_menu` и не затрагивается.

## Как собрать из mp4

ffmpeg на машине не стоял; поставлен пакет `imageio-ffmpeg` (`py -m pip install --user`), в нём
готовый exe: `%APPDATA%\Python\Python313\site-packages\imageio_ffmpeg\binaries\ffmpeg-win-x86_64-v7.1.exe`.

```
ffmpeg -i ролик.mp4 -an -r 24 -c:v libvpx -b:v 8M -crf 10 -pix_fmt yuv420p -f ivf 1440p_pc.ivf
ffmpeg -i ролик.mp4 -vn -ac 2 -ar 44100 -c:a libvorbis -q:a 3 equestria_menu.ogg
```

Нужно, чтобы был именно `libvpx` (VP8), а не `libvpx-vp9`: игровой проигрыватель ждёт VP80 в
заголовке IVF. Разрешение может быть любым, не обязательно 2560×1440.

## Ролик без звука (так сейчас и стоит)

Файл `.ogg` игре нужен обязательно: нет пары — папка пропускается целиком. Поэтому «без звука»
делается не отсутствием файла, а **беззвучным OGG** той же длины (проверено: −91 дБ). Музыку в
меню при этом ведёт отдельная подмена тем, ролик ей не мешает.

```
ffmpeg -f lavfi -i "anullsrc=r=44100:cl=stereo" -t <длина ролика в секундах> -c:a libvorbis -q:a 0 equestria_menu.ogg
```

## Что учесть

- Тестовый ролик 3,4 секунды: игра крутит его по кругу, шов будет заметен. Для настоящего — делать
  бесшовную петлю (последний кадр переходит в первый).
- Звук у теста почти беззвучный (2 кбит/с). Если в меню должна играть музыка, её ведёт отдельная
  подмена тем (`EquestriaMusic`), а не дорожка ролика.
- Размер: ванильные ролики по 130–330 МБ; наш при том же битрейте на минуту будет около 60 МБ.
